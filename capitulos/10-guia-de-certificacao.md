# Guia de Certificação

## Tópicos Mais Cobrados

- Estruturas de dados do Redis.
- Persistência (RDB e AOF).
- Cluster e alta disponibilidade.
- Segurança e autenticação.
- Monitoramento e diagnóstico.

## Resumo dos Conceitos

- **Strings**: Valores simples.
- **Hashes**: Estruturas semelhantes a JSON.
- **Lists**: Listas ordenadas.
- **Sets**: Conjuntos únicos.
- **Sorted Sets**: Conjuntos ordenados.

## Glossário Técnico

- **TTL**: Tempo de vida de uma chave.
- **Eviction**: Remoção de chaves quando a memória está cheia.
- **Replication**: Cópia de dados entre instâncias.
- **Sharding**: Distribuição de dados entre múltiplos nós.
- **Sentinel**: Mecanismo de alta disponibilidade.
